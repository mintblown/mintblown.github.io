Wie werden die acht Bits interpretiert?

ASCII: Standard-ASCII verwendet die Codes 0–127; im Byte bleibt das höchste Bit 0. Steuerzeichen können als Name eingegeben werden, zum Beispiel NUL, TAB, LF oder CR. NUL (00000000) markiert auf dem Arbeitsblatt das Textende. SPACE steht für das Leerzeichen, DEL für das Löschzeichen.

int: Vorzeichenbehaftete Ganzzahl im Zweierkomplement, von −128 bis 127. Bei führender 1 wird vom vorzeichenlosen Bytewert 256 abgezogen.

float (E4M3): Ein Vorzeichenbit, vier Exponentenbits und drei Nachkommabits: S EEEE MMM. Hier gilt die Variante E4M3FN mit Bias 7. Für normale Zahlen: (−1)S · 2E−7 · (1 + M/8). Für E = 0: (−1)S · 2−6 · M/8.

Der endliche Wertebereich reicht von −448 bis 448. Nicht exakt darstellbare Zahlen werden auf den nächsten darstellbaren Wert gerundet; bei gleichem Abstand gewinnt die Darstellung mit letztem Bit 0. Kleinste positive Zahl: 0,001953125. Positive und negative Null sowie NaN werden unterstützt; Unendlich und Werte außerhalb des Bereichs werden zurückgewiesen.

Das Arbeitsblatt nutzt ein Ein-Byte-Modell. Die Java-Typen int und double im Programm benötigen in Java mehr als acht Bit. Formatdetails: ONNX: E4M3FN.
